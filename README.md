## 📖 About the project

Quiz-Time is a console-based quiz game developed in C# as part of a school assignment focused on using AI as a programming assistant.

The objective of the assignment is to plan, develop, review, and improve a C# application with the support of an AI tool. The AI is used to explore possible solutions, explain programming concepts, suggest improvements, and support the development process without replacing the student's own work.

The game challenges players with multiple-choice questions, allowing them to test their knowledge, earn points, and compete for a place on the high-score leaderboard.

The application is designed with separate classes and responsibilities to keep the code structured, readable, and maintainable.

## ✨ Features

### **Quiz game**

Players answer multiple-choice questions presented in the console. Each question offers three possible answers.

### **Randomized questions**

Questions are selected randomly to make each game session more engaging and varied.

### **Scoring system**

Players earn points for correct answers and aim to achieve the highest possible score.

### **Lives system**

Players start with a limited number of lives. Incorrect answers can reduce their remaining lives.

### **Game rules**

Players can view the rules before starting a game to understand the gameplay, scoring system, and conditions for winning.

### **High-score leaderboard**

Players can view the leaderboard and compare their scores with other players.

### **User management**

Players enter a username to participate in the game, and their game information is managed by the application.

### **AI-assisted development**

ChatGPT was used as a programming assistant to discuss code structure, explain C# concepts, suggest improvements, and help develop ideas for the game. Suggestions were reviewed and adapted to fit the project's requirements.

## 🏗️ Code structure

The application separates responsibilities into different classes to improve readability and maintainability.

- **View** – Handles console output and displays menus, questions, game rules, and results.
- **Controller** – Coordinates the game flow and handles user interactions.
- **Services** – Contains application logic, such as question handling, scoring, and user management.
- **Models** – Represents the data used by the application, such as users and quiz questions.

## 🤖 AI usage

ChatGPT was used throughout the development process as a learning and problem-solving tool.

The AI assisted with:

- Exploring ways to structure the application.
- Understanding C# methods, classes, and programming concepts.
- Discussing approaches to handling questions, answers, points, and lives.
- Improving the organization and readability of the code.
- Developing ideas for the game rules and menu options.

AI suggestions were reviewed and adapted to the project's needs. The goal was to understand the proposed solutions and make independent decisions rather than simply copying generated code.
